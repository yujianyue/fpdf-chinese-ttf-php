FPDF 中文扩展库 · 使用说明书

版本：FPDF 1.84 + PDF_Chinese 中文扩展（兼容性修复版 + UTF-8/TTF 内嵌字体版）
适用 PHP：5.5 ~ 8.3（已实测 PHP 8.3 E_ALL 零告警生成 PDF）
原始作者：Olivier PLATHEY（FPDF） / yujianyue（中文扩展）

1. 这是什么

本库由三部分组成，提供两条中文输出路线：

文件作用
fpdf.phpFPDF 核心库：纯 PHP 实现的 PDF 生成器，不依赖任何外部 PDF 组件
chinese.phpPDF_Chinese 中文扩展：保留 GB/Big5 CID 方案，新增 UTF-8 + 内嵌字体 方案
ttf.phpTTFontSubsetter：纯 PHP 的 TrueType/OpenType 解析与子集化器
路线编码内嵌字体体积阅读端要求
A. 内嵌 TrueType（推荐）UTF-8 原生✅ 子集化内嵌几十 KB无任何要求
B. CID 引用（GB/Big5）GBK / Big5❌ 不内嵌极小需 Adobe 亚洲字体
路线 A 是本版重点升级：不再依赖阅读器字体、中英文显示一致、UTF-8 原生输入输出（无需 iconv），详见第 5 节。

2. 环境要求

项目要求说明
PHP≥ 5.5已验证 5.5 / 7.0 / 7.4 / 8.0 / 8.1 / 8.2 / 8.3
zlib可选开启后自动压缩 PDF 内容与内嵌字体流（默认开启）
GD可选仅 Image() 嵌入 GIF 时需要；JPEG/PNG 不需要
字体文件路线 A 需要一个含中文字形的 .ttf / .otf / .ttc（如文泉驿微米黑）
font/ 目录仅核心字体需要官方 FPDF 的 14 个核心字体度量 .php 文件

路线 A（AddFontTTF）与路线 B（AddGBFont）都不需要 font/ 目录；ttf.php 纯 PHP 实现，不依赖 mbstring / intl。

3. 快速开始

3.1 中文 PDF（内嵌 TrueType · UTF-8 原生 · 推荐）

<?php
require('fpdf.php');
require('chinese.php');

$pdf = new PDF_Chinese();
$pdf->AddFontTTF('wqy', '', 'fonts/wqy-microhei.ttf');  // 注册内嵌字体
$pdf->AddPage();
$pdf->SetFont('wqy', '', 20);
$pdf->Cell(0, 12, '中文 UTF-8 原生输入，无需 iconv');     // 直接传 UTF-8
$pdf->Ln(16);
$pdf->SetFont('wqy', '', 12);
$pdf->MultiCell(0, 8, '中英混排 Mixed text 自动换行。');
$pdf->Output('F', 'demo.pdf');

// 验证：pdffonts demo.pdf  →  emb=yes sub=yes uni=yes

3.2 从内存字节注册字体

$bytes = file_get_contents('fonts/wqy-microhei.ttf');   // 或从数据库/远端读取
$pdf->AddFontFromStream('wqy', '', $bytes);
$pdf->SetFont('wqy', '', 14);

3.3 中文 PDF（CID 引用 · GBK 编码 · 旧方案）

$pdf = new PDF_Chinese();
$pdf->AddGBFont();
$pdf->AddPage();
$pdf->SetFont('GB', '', 20);
$pdf->Cell(0, 12, iconv('UTF-8', 'GBK', '中文测试标题'));
$pdf->Output('D', 'demo.pdf');

5. UTF-8 + 内嵌字体：原理与限制

痛点（旧方案）本方案
依赖阅读端 Adobe 亚洲字体，缺字体出方块字体子集化后内嵌进 PDF，任何设备显示一致
UTF-8 源码必须先 iconv('UTF-8','GBK',...)UTF-8 原生输入输出，直接传字符串
断行按“非 ASCII 即 2 字节”假设，混排不精确按码点（grapheme）计算宽度与断行，支持 1–4 字节（含 emoji 码点）
  • 编码：Identity-H Type0 复合字体；glyf 轮廓 → FontFile2+CIDFontType2（紧凑子集）；CFF 轮廓 → FontFile3+CIDFontType0C。
  • 两遍渲染：构建期写占位符并收集码点，Output() 前子集化并回填内容流。
  • ToUnicode 自动生成，文字可复制、可检索（uni=yes）。
  • 断行：CJK/全角/谚文/emoji 逐字可断；Latin 按空格断。
  • 缺字行为：字体没有的字形留空显示，不报错、不影响其他字符。
字体选择建议：优先使用 TrueType（glyf）轮廓的中文字体（如文泉驿微米黑/正黑），子集化后仅几十 KB； OpenType/CFF 字体（Noto CJK、思源系列）当前为整字体嵌入（未做 CFF 子集化），可能达 10MB+。 另：TTC 取第 0 个字体；不支持竖排与复杂文本整形；内嵌前请确认字体许可允许嵌入。

6. 安全与加固（本版）

风险点修复后
null 字节注入Image / Output('F') / AddFont / _loadfont 拦截含 \0 的输入
未设字体致命错误抛出友好 No font has been set
$_SERVER['HTTP_USER_AGENT'] 未定义已做 isset 守卫（CLI 友好）
mbstring.func_overload强制 (int) 转换，PHP 8.0+ 安全
utf8_encode 弃用自实现 Latin-1→UTF-8，无依赖无告警
PDF 字符串中的 null 字节_escape 主动剔除，防 PDF 损坏
$font['subsetted'] 未定义键改用 !empty() 判断
内嵌字体流压缩标记不一致声明 FlateDecode 时真正 gzcompress（否则阅读器报错、整页空白）

安全建议：AddFontTTF / Image / Output('F') 的路径不要直接拼接用户输入；元数据建议限制长度。

7. 常见问题

Q：中文显示成方块/空白？
A：用路线 B（AddGBFont）说明阅读器缺 Adobe 亚洲字体，请改用路线 A（AddFontTTF 内嵌）；已是路线 A 则检查字体路径与字形覆盖。

Q：UTF-8 源码如何输出中文？
A：用路线 A（AddFontTTF）直接传 UTF-8，无需转码；只有坚持用路线 B 才需要 iconv('UTF-8','GBK', $s)。

Q：内嵌字体后文件有多大？
A：glyf 字体子集化后一般几十 KB；CFF 字体当前整字体嵌入，可达 10MB+，在意体积请选 glyf 字体。

Q：PDF 里文字能复制/搜索吗？
A：能。内嵌字体自动带 ToUnicode 映射（pdffonts 显示 uni=yes），复制出来是正确 UTF-8。

Q：emoji / 生僻字能显示吗？
A：取决于字体是否包含该字形；缺字形时留空不报错，其余文字正常。
